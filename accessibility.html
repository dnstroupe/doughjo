ACCESSIBILITY · IMPLEMENTATION AND LIMITS

PLAY SHOULD
INCLUDE EVERYONE.

Doughjo includes accessible interaction patterns. It has not completed a formal Section 508 evaluation and is not represented as compliant or certified.

IMPLEMENTED

  • Semantic headings, labeled navigation, a skip link, and descriptive control names.
  • Buttons for moving donuts, so dragging is never required.
  • Keyboard focus indicators, native dialogs, Escape to close, and focus return.
  • Flavor names and numbered slots alongside illustrations. Meaning does not rely on color alone.
  • Search result counts and selection updates announced through status regions.
  • Labeled checkout fields, error announcements, and focus moved to the error message.
  • Hover feedback as an extra cue. Essential help opens by click, tap, or keyboard.
  • Optional motion, respect for reduced motion preferences, and forced color styling.
  • Responsive layouts and large controls.

WHAT REMAINS

Screen reader testing, complete keyboard coverage, zoom and text spacing evaluation, all state contrast checks, and real device testing are still needed. Browser inspection and logic tests do not replace a conformance evaluation.

DEMO PRIVACY

The browser stores box size, flavor selections, and drink quantities. Contact details are used only in the open page and are not transmitted. All recipes, allergens, prices, pickup timing, and availability are illustrative and require verification before any real service.

TOOLTIPS AND TOUCH

Flavor and allergy details are opened with a labeled button. They do not depend on hover. This keeps the same information available on phones and to keyboard users.
